# Udit Chouhan - Portfolio Website

My personal portfolio site built with React + Vite. Made it to show my
projects and skills for internship applications.

## Sections

- Hero with photo and social links
- About me with hobbies
- Skills with progress bars
- Education timeline
- Projects (my actual projects with links)
- Contact form and info

## Run

```
npm install
npm run dev
```

Then open http://localhost:5173. Or just double click start.bat.

## Build

```
npm run build
```

Files go into the dist folder.
